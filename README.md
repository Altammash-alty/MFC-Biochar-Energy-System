# Biochar-Based Microbial Fuel Cell with BMS

## Overview
Developed a sustainable bioelectrochemical system using biochar electrodes for energy generation from wastewater.

## Key Features
- Biochar-based electrodes (low-cost alternative)
- Waste-to-energy system
- Integrated Battery Management System (BMS)
- Stable power output for low-power devices

## System Architecture
MFC → BMS → Battery → RC Car

## Results
- Improved electron transfer efficiency
- Stable power output using BMS
- Practical demonstration using RC car
